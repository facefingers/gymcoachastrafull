# GymCoach — Minimal Orange

Готовый статический сайт на основе вашего Github.zip.
Сборка и установка зависимостей не нужны.

## Как посмотреть на компьютере

1. Распакуйте ZIP целиком в отдельную папку.
2. Откройте `index.html` двойным щелчком.
3. Для автономного предпросмотра можно открыть `Preview.html`: в нём уже встроены
   стили, скрипты и оригинальная иконка. Справочные статьи открываются из соседних файлов.

Оба варианта содержат действующий интерфейс, а не скриншот.
PWA и service worker не запускаются из file:// или из Preview.html.
Если браузер запретит локальное хранилище, появится предупреждение; в этом случае
данные существуют только до закрытия страницы.

Если сохранена старая тёмная тема, переключите её на Light через меню ☷ справа вверху.
Настройки языка и темы сохранены.

## Что изменено

- Светлый тёплый фон, чёрная типографика, оранжевый акцент #ff6600.
- Оригинальные icon-192.png и icon-512.png сохранены байт в байт.
- Первые три тренировки — основная программа, остальные шесть — в закрытом разделе.
- Сводка текущей недели построена на реальной истории; демоданные не добавляются.
- Новое оформление тренировок, истории, статистики, итогов, советов и трёх справочных страниц.
- Мобильная нижняя навигация, закреплённые управление тренировкой и таймер отдыха.
- Суперсеты, рекомендации при их создании, замены упражнений, перетаскивание,
  рабочие веса, повторения, таймеры и калькулятор остаются в приложении.
- Дополнительные кнопки ↑ / ↓ меняют порядок на телефоне. Суперсет перемещается целиком.
- Техника и примечания раскрываются внутри упражнения.
- Историю и веса можно экспортировать в JSON: меню ☷ → «Сохранить копию данных».
  Автоматического импорта этой копии в интерфейсе пока нет.

Все 9 исходных программ сохранены без изменения их содержимого.
Тексты рекомендаций и формулы калькулятора взяты из исходного проекта; в рамках
редизайна их медицинская/тренировочная обоснованность не проверялась.

## Исправления логики

- После завершения тренировки останавливаются все таймеры.
- Таймер кардио и таймер отдыха не работают одновременно.
- Смена языка, веса, порядка, суперсетов и альтернатив не сбрасывает отметки подходов.
- Разминочные подходы с индексом -1 восстанавливаются правильно.
- Нулевое число повторений не заменяется значением по умолчанию.
- Перетаскивание работает при попадании на внутренний элемент карточки.
- Итоговое число подходов считается по программе, а не только по нажатым чекбоксам.
- Вес альтернативы рассчитывается от сохранённого базового веса;
  вручную изменённые веса альтернатив хранятся отдельно от базового упражнения.
- В статистике доступны все использованные программы, не только первые три.

## Как обновить GitHub Pages

1. Сохраните копию текущих файлов репозитория.
2. Содержимым этой папки замените файлы в папке сайта, которую публикует GitHub Pages.
   Главное: загрузить index.html, script.js, styles.css, minimal.css, minimal.js,
   service-worker.js, manifest.json, оба PNG и все три справочные HTML-страницы.
3. Подтвердите изменения в репозитории и дождитесь завершения публикации.
4. Откройте прежний адрес сайта и перезагрузите страницу.
   При необходимости закройте все вкладки приложения и откройте его повторно.
5. Preview.html, README.md и TESTING.md публиковать необязательно.

Ничего на GitHub автоматически не опубликовано.

## Важно про историю и веса

Они хранятся в localStorage конкретного браузера и адреса сайта, а не в файлах проекта.
Ключи workoutHistory, exerciseWeights, alternatives, language и theme оставлены прежними.
При обновлении на том же адресе и в том же браузере сохранённые данные остаются доступны.
Не очищайте «данные сайта» для обновления оформления.

Локально открытый HTML и опубликованный сайт — разные хранилища.
Отсутствие старой истории в локальном предпросмотре не означает её удаления на сайте.
Данные не синхронизируются между устройствами. Незавершённая тренировка живёт в памяти
вкладки: перед её закрытием или обновлением нажмите «Завершить».

## PWA и офлайн

В ZIP есть обновлённый service worker с отдельным кешем и файлами для офлайн-режима.
Установка и первичное кеширование требуют HTTPS (например, GitHub Pages).
На реальном опубликованном сайте нужно проверить установку, повторное открытие,
работу в авиарежиме и обновление старой установленной версии.
Эти проверки не выполнялись в среде сборки. Подробности — в TESTING.md.

При последующих правках файлов повышайте версию CACHE в service-worker.js,
чтобы установленное приложение получило новый набор ресурсов.

## Файлы

- index.html — основная страница.
- script.js — исходная логика с точечными исправлениями; данные всех девяти программ.
- styles.css — базовые стили исходного приложения.
- minimal.css / minimal.js — новое оформление и организация интерфейса.
- popular.html / progression.html / toning.html — исходные справочные страницы в новом оформлении.
- service-worker.js / manifest.json — PWA.
- icon-192.png / icon-512.png — ваши исходные иконки.
- Preview.html — автономная копия интерфейса для просмотра, не основная версия для публикации.
